# Reading of the sweep
- Tracked in git and written at run time: data/datasets (fixed here: gate in src/lib/dataset/target.ts, DATASET_DIR for every test server in tests/qa/pass4/lib/env.mjs).
- data/i18n written by src/app/api/i18n/route.ts: owner's decision (sign-in on /api/i18n), reported only.
- data/embeddings written by src/lib/assistant/embed.ts when the incident index hash changes: a derived cache rebuilt from the intel database; not fixed here, reported (a test server rebuilding it would dirty the repo).
- Every other writer goes to data/aws-cache, data/thunai, data/studio or a temp folder, which are git-ignored.
