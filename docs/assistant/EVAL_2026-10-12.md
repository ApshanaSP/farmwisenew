## What was wrong, and what changed

| Problem seen | Fix |
|---|---|
| "Which incidents need my verification?" listed the newest open incidents | Shortcut to the verification queue (My Tasks) before the AI router (`direct.ts`) |
| "Which department has the oldest pending work?" answered "not recorded" | Shortcut to the department-backlog tool |
| "Reported by more than one newspaper, missing from the department app" was filtered to the *Missing person* category (253) | Shortcut to news-with-no-department-record, with a new `minOutlets` filter; the correct answer is 0 (every news-only incident has one outlet) |
| "Air quality today, is it getting worse?" was once counted as air-pollution *incidents* | Shortcut to the AQI readings (also reservoir storage and rainfall), only when the question is not about complaints or incidents |
| "How many complaints were **resolved** yesterday?" answered how many were **reported** | New `resolved` reading of the question and a count by closing time (`countResolved`) |
| The "overdue / past deadline" rule never matched | The pattern held a backspace character where `\b` was meant (pre-existing); fixed |
| "Which zone needs attention **now**?" used 90 days | "now / currently" with no other period reads as the last 7 days |
| Correct answers replaced by a template because the checker rejected numbers from the code's own caveats | Caveat numbers count as allowed context |
| "three" (a word) failed the main-figure check, giving a thin template | Small figures written as words are accepted |
| "Rainfall averaged 0", "storage 34.1 full", "40 days days" | Figures keep their units (mm, AQI, % full, days…) without doubling them |
| Test-data counts repeated inside most answers | The composer no longer gets the counts; the card's caveat still shows them |
| "0 road accidents incidents" | Natural count labels ("0 road accidents") |

## Not changed / still open

- The AI router and composer still vary between runs (e.g. #2's headline became vaguer, #20 fell back to the template once on a
  number the AI computed itself). The number checker keeps such answers safe.
- `src/lib/collector/cluster.ts` has the same backspace-for-`\b` bug (street "St"/"Rd" normalisation never runs). Fixing it changes how
  incidents are grouped on the dashboard, so it is left for the owner to decide.
- The test-data caveat itself is unchanged (existing behaviour).
