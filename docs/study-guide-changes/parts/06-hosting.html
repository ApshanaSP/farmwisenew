Chapter 6Hosting, saving and what it costs

In one line

The public site runs on Modal as one container; it is the one copy that saves to AWS; the 27 November topic guard keeps every assistant on the district's work.

6.1 Hosting

  • One container (at most one, so the store is saved from one place), 1 to 4 CPU cores (2 to 4 in demo mode) and 4 to 12 GB of memory. Demo mode keeps it running all the time and never preempted; normal mode sleeps after 30 minutes with no visitors.
  • The hosted copy is the only one that saves to AWS; this PC's copy reads only. Two savers would give new rows the same ids.

Be honest about

The spend records include our own testing: 4,369 of the recorded Claude calls were automated evaluation runs, not real use. The AWS bill (S3, DynamoDB, API Gateway, Lambda) was not read for this guide. Groq, Gemini and Sarvam were used within their free tiers.

6.3 Topic guard (27 Nov)

Jarvis, Ask District IQ, the officer chat, Map Insights and the Studio analyst answer only about the district's records, the console and District IQ. A plainly off-topic question (sports, films, jokes, coding) gets one fixed sentence in English, Tamil or Tanglish, with no model call.
